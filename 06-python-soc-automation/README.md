# Python SOC Automation

**Status:** Planned  
**Level:** Beginner

## Objective
Build beginner-friendly Python scripts for simple defensive analysis tasks.

## Tools
Python 3, IDLE or another beginner-friendly editor, sample text or CSV data

## Lab Steps
1. Create a small harmless sample log or CSV file.
2. Write a Python script that reads the sample.
3. Count selected event types or summarize entries.
4. Print a readable report and handle missing or invalid input.
5. Add comments and explain each function in your own words.

## Evidence to Add
Include the script, non-sensitive sample input, output generated by your run, and a plain-English explanation.

Suggested additions after completing the lab:
- `screenshots/` — screenshots captured from your own environment
- `notes.md` — observations and explanations
- `analysis.md` or `incident-report.md` — investigation summary, where appropriate

## Questions to Answer
- What were you trying to find out?
- What did you do, and why?
- What did you observe?
- What does the evidence support, and what does it not prove?
- What would you investigate next?

## Safety and Accuracy
Use harmless sample data only. Never include credentials, tokens, or confidential organizational logs.

Do not mark this project Complete until you have performed the steps yourself, checked the results, and added your own evidence.
