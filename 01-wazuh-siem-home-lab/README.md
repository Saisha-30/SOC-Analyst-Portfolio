# Wazuh SIEM Home Lab

**Status:** Planned  
**Level:** Beginner

## Objective
Set up a small lab, forward endpoint logs, and learn to review security alerts.

## Tools
Wazuh, Ubuntu Server, VMware Workstation, Windows endpoint

## Lab Steps
1. Prepare a virtual machine for Ubuntu Server and follow the official Wazuh installation guidance.
2. Complete installation and confirm the dashboard is reachable.
3. Add a test endpoint using the current Wazuh agent instructions.
4. Confirm the agent connects and generates events.
5. Review a few alerts and explain what each one means.

## Evidence to Add
Record VM resources, software versions, agent status, alert timestamps, rule descriptions, and screenshots from your own environment.

Suggested additions after completing the lab:
- `screenshots/` — screenshots captured from your own environment
- `notes.md` — observations and explanations
- `analysis.md` or `incident-report.md` — investigation summary, where appropriate

## Questions to Answer
- What were you trying to find out?
- What did you do, and why?
- What did you observe?
- What does the evidence support, and what does it not prove?
- What would you investigate next?

## Safety and Accuracy
Do not publish passwords, enrollment keys, or sensitive network details. Do not claim successful installation or detections until verified.

Do not mark this project Complete until you have performed the steps yourself, checked the results, and added your own evidence.
