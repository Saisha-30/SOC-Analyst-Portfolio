# SOC Analyst Portfolio

A beginner-friendly portfolio documenting hands-on cybersecurity labs for entry-level Security Operations Center (SOC) Analyst skills.

## Goals
- Practice security monitoring and alert investigation.
- Learn how SIEM tools collect and analyze security events.
- Investigate authentication activity, phishing, and network traffic.
- Document findings clearly and map relevant techniques to MITRE ATT&CK.
- Build Python skills for simple defensive security tasks.

## Tools and Topics
Wazuh, Ubuntu/Linux, Windows Security logs, Wireshark, Python, phishing analysis, indicators of compromise (IOCs), incident documentation, and MITRE ATT&CK.

These are portfolio learning topics, not claims of professional experience or certifications.

## Project Documentation Standard
Each project should include:
1. Objective and learning goals
2. Lab environment and tools
3. Steps performed
4. Commands, filters, or queries used
5. Screenshots and evidence from your own lab
6. Findings and analysis
7. Lessons learned and next steps

## About
I am building practical cybersecurity skills for an entry-level SOC Analyst role. This repository will grow as I complete and document each lab.

**Safety and accuracy:** Never publish passwords, API keys, private information, or confidential logs. Only report results you personally observed; do not invent findings or screenshots.
